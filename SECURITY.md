# Security

Quill opens documents from other people, so a file that makes it crash, hang
or use huge amounts of memory is a bug we want to hear about.

Report it privately using GitHub's "Report a vulnerability" button on the
repository's Security tab, rather than in a public issue. Please attach the
smallest file that shows the problem, say which format it is, and give the
Quill version.

Only the newest release is supported while Quill is in alpha.

Quill VERSION

Quill is a word processor for the Mac that opens and saves DOCX, RTF,
OpenDocument, HTML and plain text, and keeps its own .qwp format. It is beta
software: keep copies of important documents.

Install: drag Quill to Applications.

First time you open it: beta builds are not signed by Apple yet, so macOS says
it cannot check Quill for malicious software. Click Done (or Cancel), open
System Settings > Privacy & Security, scroll down to the message about Quill,
click Open Anyway and confirm. You do this once for each new version. On
macOS 14 or earlier you can instead Control-click Quill in Applications and
choose Open.

The regular Quill runs in Apple's App Sandbox. It opens and saves only the
documents you choose, never uses the network, and asks once for the folder of a
Markdown file's pictures or a Print Merge data file. Version 0.30.0 starts with
fresh settings. Quill Debug, if this is the debug disk image, does not run in
the sandbox.

Report problems, read the known issues and get the source at
https://github.com/QuillWP/quill
